# RDS — Roller Diamond Stock

ระบบบริหารสต็อกหินขัด (Roller Diamond) ของ **บริษัท ซีทูเทค จำกัด (C2TECH)**
บันทึกการขาย ส่งทดลอง รับเข้า และเคลม พร้อม Dashboard สรุปภาพรวม ใช้งานได้ทั้งคอมพิวเตอร์และมือถือ (ติดตั้งเป็นแอปบนหน้าจอโฮมได้)

**เวอร์ชันปัจจุบัน:** v3.3.2 · หลังบ้าน Firebase (project `c2-rds`)

---

## ความสามารถหลัก

| เมนู | ทำอะไรได้ |
|---|---|
| 📈 **Dashboard** | สำหรับดูภาพรวม: ตัวเลขสรุป 5 ช่อง (ขายเดือนนี้/ปีนี้, ทดลองอยู่ที่ลูกค้า, รอเก็บเงิน, คงเหลือ), แถบต้องติดตาม, ทดลอง/รอเก็บเงินค้างนานสุด, กราฟยอดขาย, สต็อกรายรุ่น, ยอดขายตามผู้จัดทำ, ลูกค้าซื้อสูงสุด, คัดลอกสรุปสัปดาห์ |
| 📦 **คลังสินค้า** | ยอดคงเหลือแยกรุ่น · เบอร์หิน (grit) · New/Used, แจ้งเตือนต่ำกว่าขั้นต่ำ, ดูประวัติรายรุ่น, ร่างข้อความสั่งของ Supplier |
| 🕒 **ประวัติ** | ค้นหา/กรองตามประเภท ช่วงเวลา ผู้จัดทำ, แก้หมายเหตุ, ยกเลิกรายการ (คืนสต็อกอัตโนมัติ), พิมพ์เอกสาร |
| 🧰 **งานค้าง** (เดิม ภาพรวม) | เครื่องมือ Admin: ปุ่มลัดบันทึกรายการ + คิวงาน 4 แท็บ (ทดลองรอปิด · รอเก็บเงิน · เคลมค้าง · ของใกล้หมด) กดทำงานได้จากการ์ด มีช่องค้นหา และตัวเลขงานค้างบนเมนู |
| ⚙️ **ตั้งค่าระบบ** (Admin) | จัดการรุ่นสินค้า, สต็อกขั้นต่ำ, รายชื่อผู้จัดทำ/ลูกค้า, ชื่อภาษาอังกฤษ, **จัดการผู้ใช้** |

**ประเภทรายการ** (ปุ่ม ＋ บันทึกรายการ)

- 💰 **ขายสินค้า** — ตัดสต็อกทันที · เลือกได้ว่า **ชำระแล้ว** หรือ **รอเก็บเงิน** (ยอดขายนับวันที่ส่งของเสมอ แล้วกด "ชำระแล้ว" ภายหลัง · แก้สถานะได้ในหน้าประวัติ)
- 🧪 **ส่งทดลอง** — ภายหลังปิดเป็นขาย (ชำระแล้ว/รอเก็บเงิน · เลือกนับยอดวันนี้หรือวันที่ส่งของได้) หรือรับคืน
- 📥 **รับเข้า** — หินใหม่ (New) หรือรับคืนหินใช้แล้ว (Used)
- 🛡️ **เคลมสินค้า** — เปลี่ยนหินให้ลูกค้า แนบรูปได้ และปิดเคลมภายหลัง

**อื่นๆ**

- บันทึกย้อนหลัง (backdate)
- พิมพ์ **ใบรับสินค้า / ใบเคลมสินค้า** ขนาด A4 (ต้นฉบับลูกค้า + สำเนาบริษัท)
- สลับภาษา **ไทย / English** — ชื่อลูกค้าและหมายเหตุแปลอัตโนมัติด้วย Cloud Translation
- รูปเคลม: ถ่าย/เลือกรูป ระบบย่อขนาดก่อนอัปโหลด ปัดดูรูปได้

## ผู้ใช้และสิทธิ์

| Role | สิทธิ์ |
|---|---|
| **Admin** | ทำได้ทุกอย่าง รวมถึงจัดการผู้ใช้ |
| **Guest** | ดูข้อมูลได้อย่างเดียว (ค้นหา กรอง สลับภาษาได้) — ใช้สำหรับ Supplier |

- สิทธิ์ตรวจซ้ำที่เซิร์ฟเวอร์ทุกคำสั่ง ไม่ได้แค่ซ่อนปุ่ม
- **จัดการผู้ใช้** (ตั้งค่าระบบ › ผู้ใช้): สร้าง, แก้ชื่อ/role, รีเซ็ตรหัสผ่าน (ได้รหัสชั่วคราว ผู้ใช้ต้องตั้งใหม่ตอน login), ปลดล็อก, ลบ
- บัญชี `admin` หลักลบหรือลดสิทธิ์ไม่ได้

**Session**

- login ครั้งเดียวใช้ได้ 30 วัน และต่ออายุอัตโนมัติเมื่อเปิดแอปตอนเหลือไม่ถึง 7 วัน
- รหัสผิด 5 ครั้ง ล็อกบัญชี 15 นาที (Admin ปลดล็อกได้)
- รหัสผ่านเก็บแบบ hash (scrypt) ไม่มีใครเห็นรหัสจริง รวมถึง Admin

## โครงสร้างระบบ

```
หน้าเว็บ (GitHub Pages, ฝังใน Google Sites)
        │  Firebase SDK · httpsCallable
        ▼
Cloud Functions  (asia-southeast1)
        │
        ├── Firestore   ข้อมูลสต็อก / ประวัติ / ผู้ใช้
        ├── Storage     รูปเคลม (claimPhotos/)
        └── Cloud Translation API
```

- หน้าเว็บ **ไม่เข้าถึง Firestore/Storage โดยตรง** — rules ปิดไว้ทั้งหมด ทุกอย่างผ่าน Cloud Functions
- Firebase web config ใน `script.js` เป็นข้อมูลสาธารณะตามปกติของ Firebase ไม่ใช่ความลับ

### ไฟล์ในโฟลเดอร์นี้ (หน้าเว็บ)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ |
| `script.js` | ทั้งหมดของแอป: หน้าจอ, login, เรียก Cloud Functions, พิมพ์เอกสาร, แปลภาษา |
| `style.css` | หน้าตา (sidebar บนคอม / แถบเมนูล่างบนมือถือ) |
| `sw.js` | Service worker — ให้ติดตั้งเป็นแอปได้ และโหลดไฟล์ล่าสุดเสมอ |
| `manifest.json`, `icons/` | ชื่อและไอคอนแอป |
| `Google Script` | โค้ด Apps Script เดิม (v2.7.3) เก็บไว้อ้างอิง — ระบบไม่ได้ใช้แล้ว |
| `migration-firebase/` | ข้อมูลที่ใช้ย้ายระบบ (มีชื่อลูกค้า — **ไม่ควรขึ้น GitHub**) |
| `backup-before-*/` | ไฟล์สำรองก่อนแต่ละการแก้ไข |
| `v3-test/` | ชุดทดสอบก่อนย้ายระบบ |

## การอัปเดต

| แก้อะไร | ต้องทำ |
|---|---|
| หน้าเว็บ (`index.html` / `script.js` / `style.css`) | commit + push ขึ้น GitHub แล้วรีเฟรช (Ctrl+Shift+R) · ถ้าแก้ไฟล์หน้าเว็บ ให้ขยับเลขเวอร์ชัน 3 จุด: `?v=` ใน `index.html` (style.css/script.js), `CACHE_NAME` + `SHELL_FILES` ใน `sw.js` และ `APP_VERSION` ใน `script.js` · หลัง push รอ GitHub Pages ประมาณ 1–10 นาที แอปจะรีโหลดเป็นเวอร์ชันใหม่ให้เอง |
| หลังบ้าน (`functions/`) | ที่ `C:\dev\c2-rds-firebase` รัน `firebase deploy --only functions` |
| rules (Firestore/Storage) | `firebase deploy --only firestore,storage` |

> ⚠️ **ห้ามรัน `node import.js ... --replace` อีก** หลังเปิดใช้งานจริงแล้ว คำสั่งนี้จะเขียนทับข้อมูลทั้งหมดด้วยไฟล์ Excel เก่า

## แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| login แล้วขึ้น "เชื่อมต่อไม่ได้" | Functions ขึ้นไม่ครบ → รัน `firebase deploy --only functions` ซ้ำ แล้วตรวจใน Firebase Console › Functions |
| หน้าเว็บยังเป็นเวอร์ชันเก่า | กด Ctrl+Shift+R · บนมือถือปิดแล้วเปิดแอปใหม่ |
| บัญชีถูกล็อก | รอ 15 นาที หรือ Admin กดปลดล็อกในหน้าจัดการผู้ใช้ |
| ลืมรหัสผ่าน | Admin กดรีเซ็ตรหัสผ่าน แล้วส่งรหัสชั่วคราวให้ผู้ใช้ |
| แปลภาษาหรืออัปโหลดรูปไม่ได้ | ตรวจว่าเปิด Cloud Translation API แล้ว และ service account ของ Functions มีสิทธิ์ใน IAM |
